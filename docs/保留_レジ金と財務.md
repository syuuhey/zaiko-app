## §4 フェーズ2: レジ金の入出金取込と仕分け

移植元: `~/在庫管理表/レジ金仕分け/index.html`(ロジックの正。読むだけで編集しない)

### 画面
- `/dashboard/cash`(店長ログイン必須)

### 取込
- Airレジ「入出金履歴CSV」(Shift-JIS。UTF-8保存し直しにも対応)。列: 店舗番号/店舗名/レジID/レジ担当者ID/レジ担当者名/営業日/取引日時/入出金タイプ/入出金額/コメント
- Airレジ「精算履歴」は画面コピペの貼り付けで取込(CSV出力が無いため)
- 同じ行を二度取り込んでも重複しない(§6 の一意キー)
- 取込先の店舗は画面で選んだ店舗。CSVの店舗番号と食い違う場合は取込を止めて警告する

### 仕分けルール(単体HTMLと同じ)
- 入出金タイプが **預入金・つり銭準備金(釣銭準備金)** → `現金移動`。経費にしない
- 入出金タイプが **過不足** → `現金過不足`
- それ以外の出金 → コメントのキーワードで科目を自動判定。該当なしは `未分類`
- 科目を手で直したら、そのコメントは次回から同じ科目(辞書に記憶)
- 科目は `expense_categories` を使う(新しい科目マスタを作らない)

### 経費への計上
- **自動では計上しない。** 行ごと(または選択した行をまとめて)「経費に登録」を人が押す
- 登録時、同じ店舗・同じ日・同じ金額の経費が既にあれば警告を出す(LINEレシートbotとの二重計上防止)
- 登録済みの行は `expenses` の行とひも付け、再登録できないようにする

### 読み方(実データで検算済み。変えない)
- 精算金額 = その日の預入金を引く前のレジ内現金。翌日繰越 = 精算金額 − 同日の預入金
- 現金売上(推定) = 締め残高 −(前日繰越 − 出金・つり銭)
- 現金売上 0 の日はキャッシュレスのみの日で正常。エラーにしない

## §5 フェーズ3: 財務の状況

### 画面
- `/dashboard/cash` の上部、またはダッシュボードのサマリー(`/dashboard`)に追加

### 表示
1. **日別の現金**: 前日繰越 / 現金売上(推定) / 出金・つり銭 / 預入金 / 締め残高 / 過不足
2. **月のまとめ**: 月末のレジ内現金、預入金の合計、過不足の合計、未分類の件数、経費未登録の件数
3. **突合**: Airレジ由来の預入・過不足と、レジ締め報告(`register_closings.deposit` / `over_short`)が同じ日で食い違えば赤で表示
4. **推移**: 直近6か月の税抜き売上・経費合計・営業利益(`computePnl()` を月ごとに呼ぶ。計算を複製しない)

### やらないこと
- 銀行口座残高・借入・未払金の管理(貸借対照表は作らない)
